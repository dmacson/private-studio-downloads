Private Studio for Android 0.3.0

Download Private-Studio-Android-0.3.0.apk below and open it on Android 10 or later. This is a signed Android installation package, not a Play Store listing.

This companion controls an existing Private AI Studio 0.3.0 installation on your Windows PC. Your PC performs image, video and voice generation; the phone displays the results and can save them to Android Downloads.

Setup: install Tailscale on the PC and phone, sign in to the same account, then enable private phone access in desktop Settings. Enter the private HTTPS address in the Android app and pair it using a one-time code from the PC. The PC must remain on with the studio running. No public router port forwarding is required.

For the complete setup and feature guide, download Android Help Sheet.html below. The APK contains no personal library, model weights, PC address or pairing credentials.

This release provides the Android companion only. It is not a standalone AI generation engine.
